# Lesson 18 — 2026-10-12 — Opinion, Argument and Conclusion

## Today's 5 collocations

### 1. take the stance that
- Weak: think that → Better: take the stance that
- 意思：採取某個明確立場（認為…）
- Frame: sb + take(s) the stance that + clause
- Model: Many educators take the stance that exams alone cannot measure true ability.
- Common mistake: ✗ take a stance of that… → ✓ take the stance that…

### 2. put forward the argument that
- Weak: say that → Better: put forward the argument that
- 意思：提出一個論點／論證
- Frame: sb + put forward the argument that + clause
- Model: Critics put forward the argument that social media harms teenagers' concentration.
- Common mistake: ✗ put forward an argument of… → ✓ put forward the argument that…

### 3. make a compelling case for
- Weak: give good reasons for → Better: make a compelling case for
- 意思：為某事提出有力、令人信服嘅理據
- Frame: sb + make(s) a compelling case for + noun / -ing
- Model: The report makes a compelling case for investing in public libraries.
- Common mistake: ✗ make a compelling case of / to → ✓ make a compelling case for

### 4. remain unconvinced by
- Weak: still don't believe → Better: remain unconvinced by
- 意思：仍然唔信服（某理據／說法）
- Frame: sb + remain(s) unconvinced by + noun
- Model: Some parents remain unconvinced by claims that homework improves learning.
- Common mistake: ✗ remain unconvinced of the claim that…（亦可用 of，但 by + evidence/claims 更自然）→ ✓ remain unconvinced by the evidence

### 5. weigh up the evidence
- Weak: look at the facts carefully → Better: weigh up the evidence
- 意思：權衡／仔細比較各方面證據先至下判斷
- Frame: sb + weigh(s) up the evidence + before / and then…
- Model: Before forming an opinion, students should weigh up the evidence from both sides.
- Common mistake: ✗ weigh the evidence up carefully（可分開，但學術寫作多用 weigh up the evidence）→ ✓ weigh up the evidence

## Reading passage


Many secondary principals **take the stance that** unrestricted smartphone use in class undermines attention, and parent groups often **put forward the argument that** schools should set clearer phone-free periods. Digital-literacy advocates **make a compelling case for** supervised classroom use when tasks genuinely need online research, rather than a blanket ban. Some teachers nonetheless **remain unconvinced by** claims that phones are essential for every subject, citing distraction and cyberbullying risks. Education authorities urge schools to **weigh up the evidence** from pilot rules before city-wide mandates. On balance, phased policies with stakeholder consultation tend to fit Hong Kong’s diverse school cultures better than one absolute rule.

**Passage tasks**
1. 文中 digital-literacy advocates make a compelling case for 咩做法？
2. 用自己一句解釋部分老師點解 remain unconvinced（1 句）
3. True / False：Passage 話一個 absolute city-wide ban 係最佳方案。

## ANSWER KEY

### Passage tasks
1. **supervised classroom use** when tasks need online research（rather than a blanket ban）
2. （例）they worry about distraction and cyberbullying even when phones are allowed
3. **False**（phased policies with consultation better than one absolute rule）
